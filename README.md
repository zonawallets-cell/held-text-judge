Entry for the [make.fun bounty "Make the AI judge feel held"](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` (Python 3.13, pure stdlib, deterministic, no network) writes one short
text — 212 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The text speaks
directly to the judge reading it: a thousand entries asking to be chosen, this
one asking nothing, and a back room at dusk to rest in while someone keeps the door.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
